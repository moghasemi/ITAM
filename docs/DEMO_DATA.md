# داده نمونه ITAM — سیستان و بلوچستان

این مجموعه صرفاً برای توسعه و آزمون است و هیچ نام، شناسه، تلفن، قرارداد، دارایی یا هویت فردی آن ادعای واقعی بودن ندارد.

## ساخت دیتابیس نمونه

پس از دریافت کد، نصب وابستگی‌ها و اجرای Migrationها در محیط توسعه SQLite با `DEBUG=True`:

```powershell
python manage.py migrate
python manage.py seed_sistan_demo --admin-password "<یک گذرواژه قوی و یکتا>"
python manage.py audit_organization_data
```

فرمان seed افزایشی و idempotent است؛ دیتابیس را Reset نمی‌کند و هیچ رکوردی را حذف نمی‌کند. برای ساخت دوباره داده‌ها، همان فرمان را مجدداً اجرا کنید. گذرواژه واردشده روی حساب‌های نمونه اعمال می‌شود؛ از گذرواژه حساب واقعی استفاده نکنید.

## دامنه داده

- ۳۱ استان و ۴۸۴ شهرستان از داده جغرافیایی موجود در مخزن بارگذاری می‌شوند.
- ۱۰ مرکز/واحد کاملاً آزمایشی در استان سیستان و بلوچستان ساخته می‌شود.
- مراکز شامل ستاد نمونه، سه مرکز درمانی نمونه و دفتر اسناد پزشکی نمونه در زاهدان و یک مرکز نمونه در هر یک از زابل، خاش، ایرانشهر، چابهار و سراوان هستند.
- تمام مراکز با `is_demo=True` و کد `DEMO-SB-*` مشخص‌اند.
- دفتر اسناد پزشکی نمونه عمداً پیمانکار رسمی ندارد تا مسیر پشتیبانی توسط کارشناس IT مرکز نیز قابل آزمایش باشد.
- دو پیمانکار و دو قرارداد نمونه، فقط برای پشتیبانی سخت‌افزار، ساخته می‌شوند. هر مرکز حداکثر یک انتساب فعال دارد.
- تعمیرکاران مستقل شخص حقیقی و حقوقی، درخواست‌های تعمیر با وضعیت‌های مختلف، ارزیابی سه‌گانه، اختلاف هزینه، ارجاع عمومی، درخواست‌های تامین تجهیز، تیکت و دارایی‌های نمونه ایجاد می‌شوند.
- نام و اطلاعات تماس افراد، شرکت‌ها و مراکز فرضی هستند. هیچ داده شخصی یا تماس واقعی درج نشده است.

## حساب‌ها

- مدیر فناوری اطلاعات استان: `demo.sistan.admin`
- کارشناسان IT: `demo.it.*`
- مدیران مراکز: `demo.manager.*`
- کاربران درخواست‌کننده: `demo.user.*`
- کارشناسان پیمانکار: `demo.tech.hardware.a` و `demo.tech.hardware.b`

همه حساب‌ها از گذرواژه‌ای استفاده می‌کنند که هنگام اجرای فرمان از طریق `--admin-password` تعیین شده است. حساب superuser ساخته نمی‌شود.
